# Contributing to 4399123.com

Thank you for wanting to build 4399123.com with us.

This community is for people who are learning, experimenting, building, and sharing. Small contributions are welcome.

## Ways To Contribute

You can help by:

- Fixing typos in docs or content
- Adding a Vibe Coding project note
- Improving the homepage, blog, or Vibe Coding page
- Testing the site on desktop or mobile
- Suggesting better wording
- Reporting bugs
- Improving accessibility
- Adding beginner-friendly tutorials

## Beginner Workflow

1. Open an issue and describe what you want to improve.
2. Fork the repository.
3. Create a new branch.
4. Make a small change.
5. Submit a pull request.

If you are new to GitHub, it is completely fine to start with a typo fix or a small docs update.

## Local Development

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm run build
```

## Content Contributions

Project entries live in:

```txt
content/projects/
```

Journal entries live in:

```txt
content/thoughts/
```

Interesting notes live in:

```txt
content/interesting/
```

Please keep content practical, respectful, and useful for people learning AI-assisted building.

## What Not To Submit

Please do not submit:

- Passwords
- API keys
- Private user data
- Production `.env` files
- Database dumps
- Server credentials
- Copyrighted material you do not have permission to share

## Pull Request Style

Keep pull requests focused. A small, clear pull request is much easier to review than a huge one.

Good examples:

- Fix README typo
- Add one project card
- Improve mobile layout for the blog page
- Add a beginner FAQ page

## Community Tone

Be kind to beginners. The goal is to make building feel possible.
