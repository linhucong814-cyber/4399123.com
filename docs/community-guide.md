# 4399123 Community Guide

4399123.com is a Vibe Coding community for people who use AI to make websites, tools, experiments, writing, visuals, and small products.

## What We Build

- AI coding experiments
- Small interactive tools
- Project journals
- Prompt notes
- Beginner tutorials
- Community showcases

## Who Can Join

You are welcome if you are:

- New to coding
- Learning AI-assisted development
- A designer or product builder
- A developer exploring faster workflows
- A writer documenting the building process
- A maker who likes small experiments

## How To Participate

- Share a project
- Write a short note
- Suggest a feature
- Fix a typo
- Improve a page
- Test on your phone
- Help another beginner

## Community Principle

Make building feel possible.
