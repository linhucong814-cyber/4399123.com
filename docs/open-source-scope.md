# Open-Source Scope

This repository is the public first version of 4399123.com.

## Included

- Front-end source code
- Homepage
- Blog / Journal page
- Vibe Coding page
- Community page front-end
- Search entrance
- Public content files
- Public assets needed by the site
- Open-source community docs
- GitHub contribution templates
- CI workflow for build verification
- Sanitized server audit notes

## Excluded

- Production database
- Django `SECRET_KEY`
- Admin accounts
- Email settings
- API keys
- Server deployment files
- Private user data
- Runtime logs
- Local virtual environments
- Installed dependencies
- Deployment archives and local backup folders

## Why

The goal is to make 4399123.com easy to learn from and contribute to while keeping production systems and user privacy safe.
