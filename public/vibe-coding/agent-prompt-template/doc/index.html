公众号模板

网页到公众号文章

把网页内容、图片素材和写作目标整合为可执行的公众号文章生成任务。

  • 收集网站内容和图片素材。
  • 支持 image 生成配图或搜索配图。
  • 最终文章保存为 Markdown 文件。
短视频生产

HyperFrames 视频 + VoxCPM 配音

从导演视角处理叙事、节奏、镜头语言、情绪曲线和声音设计。

  • 输出 HyperFrames 可执行视频任务。
  • 规划 VoxCPM 配音提示词。
  • 支持克隆音频和 4:3 画幅要求。
评论生成

回复他人评论

从创建 skill 的模板重构为直接生成评论内容的模板，降低使用成本。

  • 输出最推荐评论和多条备选。
  • 包含最容易火、自然共鸣、犀利锐评、幽默版、高级版。
  • 强调真实、自然、像真人表达。
API 配置

用户自定义 AI API

页面新增 AI API 配置区，让用户自行接入不同模型服务。

  • 支持 Base URL、Provider、Model ID、API Mode、API Key。
  • 支持 openai-completions、anthropic-messages、openai-responses、google-generative-ai。
  • API Key 只保存在当前页面内存，不写入浏览器存储、日志、响应或构建产物。
