How it works

        
四步启动 Vibe Coding

      

      

        
01
输入想法
用自然语言描述你想做什么，不需要先写完整需求文档。

        
02
生成指令
把目标、技术、功能、视觉和检查要求自动整理成 /goal。

        
03
粘贴到 Codex
复制结果，直接交给 Codex 执行，减少反复解释成本。

        
04
运行并迭代
打开页面、反馈问题、继续打磨，让想法逐步变成作品。
